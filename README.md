# Proyecto Git

Este proyecto se realiza como parte de una actividad para aprender a utilizar Git y GitHub.

## Funcionalidades planeadas

- Aprender a registrar cambios en un repositorio.
- Conocer como trabajar con ramas y versiones.

## Equipo de trabajo

Este proyecto fue realizado para practicar los comandos básicos de Git y aprender a utilizar GitHub.

## Cambios de la rama

En esta rama se agregaron cambios para practicar el uso de ramas en Git.
